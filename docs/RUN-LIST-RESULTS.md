# 任务列表按需读取实测

2026-09-10，在真实工作台读取最近80条运行记录。摘要响应为88,577字节，完整响应为691,992字节，减少约87%。两份结果的任务ID、状态、依赖、伙伴身份和像素形象逐项一致。服务端数据库与原成果文件没有删减。

浏览器点击任务与输出，查看真实成果文件、完整会话ID、成果目录与验收结论；等待摘要列表刷新后，已经打开的完整详情和文件预览仍然保留。任务执行器和内部调度继续读取完整运行记录；外部需要完整列表时可指定 `compact=false`，查询单条任务仍返回完整详情。
