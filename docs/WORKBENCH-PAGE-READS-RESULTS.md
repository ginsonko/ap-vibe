# 工作台按页面读取实测

2026-09-10。工作台现在只读取当前页面需要的大块资料。首页保留真实监看图表，项目页读取项目档案，逻辑观察与 AP 认知读取对应状态；工作室、帮助和历史整理不再额外读取整份项目状态和记忆。

真实浏览器完成四组场景：

| 操作 | 实际结果 |
| --- | --- |
| 延迟初次项目目录返回，在工作室选择任务并填写草稿，再释放目录 | 所选标签、任务和未发送文字保留；没有无关的 state、data、overview 请求 |
| 展开普通多人留言、选择收件人后再收起 | 普通复选框可操作，草稿保留；历史消息有独立高度和滚动区域 |
| 从帮助进入首页，再进入项目与记忆 | 帮助不读取整份资料；首页取监看状态；项目页取对应档案 |
| 进入逻辑观察与 AP 认知 | 读取所需状态，不额外读取项目记忆包；没有意外写入或模型调用 |

1440 像素桌面截图已经逐张检查，测试期间无页面错误。按页请求与 gzip 是两项独立改进：前者避免无用读取，后者减少必须传输的字节；不能据此断言整个前端已消除所有性能问题。工作室仍有自己的轮询，生产主包约762KB，其拆分和长期大数据表现仍有优化空间。

本机原始网络请求、截图和检查结果保存在私有 `.local-acceptance/page-reads-20260910/`，不随公开发行包含用户数据。此前两次验收脚本使用了错误的界面标签，已保留失败记录；修正定位后完成上述验证，没有改动产品数据来制造通过。
