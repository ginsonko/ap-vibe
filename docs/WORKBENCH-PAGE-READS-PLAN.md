# 按当前页面读取所需资料

现场 gzip 已将 3.59MB 的 state 缩至 642KB，但所有页面仍每十秒同时请求 state、data 和会话总览。协作工作室本来有自己的数据源，正在填写消息仍会被迟到的初始项目 ID 重挂载，草稿和所选标签可能丢失。仅缩小传输无法解决这个工作流问题。

改动：保留健康与项目目录的共同读取；首页/会话读取会话总览，首页/逻辑观察/AP认知读取 state，项目与记忆读取 data。未请求的已有同项目数据保留，不制造错误，不用旧项目数据填新项目。切页使旧批次失效，按新页面加载；刷新、写入后更新和可见性恢复使用同一流程。全局会话、工作室、帮助和归类页面不因默认项目异步到达而重建；项目相关页面继续隔离。工作室初始项目为空时补上有效默认值，但不改变用户已选择的目标。

对抗审查：减少请求不能删除正文或资料入口；切页或快速切项目时晚响应不能污染新页；略过的请求不能成为“正在加载/断线”的假信号。项目保存/逻辑观察操作后须刷新对应资料。主页曲线仍用真实已有消息。需用实际浏览器延迟目录验证草稿/标签保持，检查各页网络请求和主页/项目档案实际内容；不以打包成功替代行为验收。工作室每四秒仍有自己的轮询，其列表瘦身和长时间运行另行处理。
