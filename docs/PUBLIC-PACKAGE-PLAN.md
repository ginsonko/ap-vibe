# 内测发行包准备

## 2026-09-10 最终交付执行稿

目标：Windows 个人用户把宣传图或口令交给 Codex 后，获得可运行的工作台、明确的第一步和可持续项目档案。交付 README、安装说明、完整源码及预构建界面、非商用许可证、宣传长图、带配音字幕的产品教程，以及可核验的 GitHub 安装入口。

执行顺序：先重写说明书和检查公开文件；复用九套像素角色与公开演练资料，生成一张缺失的品牌场景图，再本地排版长图和制作教程；建立私有仓库作为可审查的发行候选，核对远端文件和新用户安装入口，最后公开。已完成的分项验收只读取收据，不重新提交模型请求。最终包验收使用隔离配置，不覆盖日用工作台。

宣传创意：以“让每一次接力，都接得住”为主线。先解释重复交代、任务失联、旧决定丢失，再展示实时现场、共享档案、按章恢复、协作与验收；以三步安装和可直接复制的口令结束。视觉使用深色工作室、薄荷绿与暖杏色、模型像素伙伴，正文由本地排版保证中文准确。教程分为认识产品、日常使用、协作、安装、费用与边界，画面明确区分界面演示和真实验收结论。

对抗审查：不能把动画等同真实任务、把章节齐全等同内容正确、把实验 AP 等同长期学习有效；不能将私人截图、原始参考图、密钥、用户会话和未知根文件发布。官方名称不表示背书。安装口令在仓库真实存在且路径确认后才进入最终画面。文字不能依赖生图模型准确写长中文。失败生成只查询原请求，不重放。生成图片单张上限 5 元，本地剪辑无需视频生成；费用以回执为准。

验收：长图原尺寸与缩小阅读检查，视频逐段画面、完整旁白/字幕、时长音轨检查；README 链接与发布清单扫描；最终包正常安装、实际 URL、Skill/MCP 配置与一次首次入口任务，保留失败与修复证据。另一实体机器、真实 Windows 重启和长期净收益列为持续内测事项。

用户已授权合格后发布GitHub，以及个人非商用、允许二开并署名的许可证。准备时先列明实际发布文件，排除会话、数据库、配置、密钥、私人验收和未知文件；保留预构建前端以便首次安装不依赖Node。没有通过的流程在内测清单中明确记录。

源树只读扫描目前351个可见候选文件、约18MB；发现README仓库owner占位和三处测试用合成token模式，未发现真实凭据模式。这个正则扫描不代替全部内容检查。根目录未知文件0保持原样，显式发布清单不收录它。
