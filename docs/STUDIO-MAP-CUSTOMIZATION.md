# 调整你自己的像素工作室

可以直接告诉 Codex：“保留任务协作功能，把工作室改成我喜欢的布局，增加一层和几个工位；检查角色不重叠、走路不穿墙，最后打开浏览器让我看。”

当前地图是1600×1150的本地矢量场景，八个区域，29个工作/交流位置和6个床位。角色动画使用本地像素图集；界面动画不负责实际任务调度。

| 要改什么 | 修改入口 | 需要保留 |
|---|---|---|
| 楼层名、装饰、颜色 | `apps/studio/src/office-floors.json` | 每层唯一数字id，name、description；palette为可选色板 |
| 房间尺寸、工位和床位 | `apps/studio/src/office-layout-v2.json` | 唯一席位id、room_id、actor落点、门与导航连接 |
| 桌椅、植物、墙面画法 | `apps/studio/src/OfficeSceneSVG.jsx` | 使用配置坐标，绘图组件不修改全局状态 |
| 人多时楼层安排 | `apps/studio/src/OfficeLayout.js` | 一个位置一名角色；名单中保留未在当前层显示的人 |
| 走路、碰面、回放 | `apps/studio/src/office-motion.js`、`OfficeActors.jsx` | 宿主真实状态、移动路径、回放暂停与倍速 |

楼层配置新增一项即可出现新的楼层；当前各层共用安全的房间与导航结构，通过色板、地毯和家具区别。它不是每层独立的寻路网格。若要不同楼层拥有完全不同的墙体，需连同每层的房间、门与寻路数据一起扩展，不能只移动墙的画法。

工位的 `actor` 是角色中心，`approach` 是走廊到达入口。以150×116的角色和名称区域检查空间：不要让两个角色遮挡，也不要把工位放在门或主要路径上。房间的 `enclosure: open` 是开放区域；封闭房间必须配置真正位于边界的门。导航节点和边必须连通。

在同一页面可同时显示实时地图和回放。SVG图案使用组件自己的ID，装饰只从当前楼层参数读取，避免回放改变实时地图。

修改后先执行：

```powershell
cd apps/studio
node --test tests/office-layout-v2.test.mjs tests/office-motion.test.mjs
npm run build
```

然后真实打开工作室，逐层切换，检查角色姓名可点、图案加载、从房间穿门、宿舍床位、回放暂停/倍速、手机宽度。自动检查覆盖当前35个位置共1225对路径；增加位置后按新位置数重新检查。视觉质量仍以实际截图和用户查看为准。
