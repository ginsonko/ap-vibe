## 使用边界

- 详细逐应用范围见[跨应用支持表](CROSS-APP-SUPPORT.md)。PI Desktop、DSH、GenericAgent Admin 和 ZCode 尚无本版工作室托管执行端；PI CLI 只有格式适配，未进行本轮原生模型验收。
- Hermes 的 CLI 和共享会话读取通过，不等于桌面 GUI 已全面验证。MiMo Desktop 需要内测资格，本轮使用官方 CLI。WorkBuddy 已安装，但未确认登录和任务执行，暂不列为支持。
- 普通第三方终端通过下次 Hook / Skill 读取返回消息，不承诺即时唤醒任意窗口；不会为同一会话再启动一个并发写入者。
- 各原生执行端的逐请求用量、重试与预算拦截能力不同；本地金额不代表供应商账单，也不能证明节省费用。
- 这是同机受控验收。另一台电脑、多日运行、不同客户端版本和真实用户复杂项目仍需内测反馈。AP 多模态认知和长期净收益未因本次接入而得到证明。

个人非商业内测；商业使用需要另行授权。完整包、版本和 SHA256 以同一 Release 的应用包与清单为准。安装入口为[文本口令](BETA-INSTALL-PROMPT.txt)。
