# Agent 工作室角色素材与状态合同

状态：九套透明静帧保留，DeepSeek新增32帧基础动作；事件地图、通道移动、消息演出与用户PNG/动作图集导入已实现并经浏览器检查。其余八套完整动作继续制作。辨识方向见 [角色美术要求](AGENT-CHARACTER-ART-DIRECTION.md)，操作见 [工作室说明](AGENT-STUDIO-OFFICE.md)。

## 四类身份分别保存

`agent_id` 标识一个可起名、可分工的伙伴。`executor_kind` 标识 Codex 或 Claude Code 等执行器。`model` 是它实际调用的模型。`appearance_id` 是可自由选择的外观。

外观不改变模型、权限、能力或任务分配。同一个模型可有多个 Agent；同一个 Agent 换模型后可保留自己的外观。未知模型使用中性外观并允许自选，不能错误显示成 OpenCode。OpenCode 参考是执行器拟人外观，不能把它列成一种模型。

## 图集文件与动作

每套素材包含透明 PNG 图集、机器可读 manifest、完整预览与来源说明。manifest 声明：

| 字段 | 含义 |
| --- | --- |
| `schema_version` | 图集格式版本 |
| `appearance_id` / `version` | 外观唯一键和资产版本 |
| `display_name` / `family_hint` | 展示名称、建议家族；建议不限制配置 |
| `atlas` / `sha256` | 本地相对文件路径、文件哈希 |
| `frame_width` / `frame_height` | 原始像素尺寸；先用 64×64，细节不足可整套升到 96×96 |
| `anchor` | 同一套所有帧一致的脚底锚点 |
| `animations` | idle、walk、work、read、talk、wait、rest 的帧序列、帧率、方向和循环设置 |
| `fallbacks` | 缺方向或动作时明示可用静帧，不把静帧谎称完整动画 |
| `attribution` | 制作者、参考来源与分发许可状态 |

第一版验收最低要求是九套独立正面静帧可辨识、统一像素比例与透明边缘；静帧通过后才生产动画。完整地图交付要求左右/前后走路、待机、工作、阅读、交谈、等待和休息动作实际可用。动画应有真实肢体、头发或尾部帧间变化；整体上下移动不是完整走路素材。

## 真实事件到视觉状态

| 真实事实 | 视觉表现 | 不能推断的内容 |
| --- | --- | --- |
| 启动中或运行中，阶段未知 | 工位显示“处理中” | 不根据 prompt 关键词判定它正在写前端 |
| 执行器报告读取工具事件 | 资料查阅动作，显示工具来源 | 读到资料不等于正确理解 |
| 明确写文件或代码工具事件 | 工程动作，关联真实输出 | 文件写入不等于测试通过 |
| 已登记依赖等待 | 等待区、列出依赖 | 不把等待表现为模型正在思考 |
| provider 返回、未验收 | 验收区等待 | 不显示“已完成” |
| 独立 review 接受 | 完成标记后回空闲区 | 只代表这一任务通过 |
| uncertain 或断联 | 保留现场，标注最后更新时间 | 不自动循环工作动画制造活跃感 |
| 明确 failed | 需要帮助，保留成果和交接入口 | 动画不触发换人或重放请求 |
| 持久消息记录 | 显示送达/已提供状态与气泡 | 已提供不等于已读 |

系统在消息持久化后立即投递，走近对方和气泡展示只负责呈现，不等待动画结束。历史消息进入回放时明确显示回放；不得作为新消息重复投递。

一个 Agent 存在多个运行时，展示全部活动数并优先显示仍活跃的运行；不能只取最新已完成记录隐藏旧的运行。超过一个画面的角色采用缩放、区域列表或分页，不能静默截断为九人。普通列表和减少动画模式保留相同的任务入口、状态与消息。

## 素材验收

1. 在实际地图尺寸与放大尺寸分别检查；移除姓名和标签后仍能从轮廓、发色、配饰识别九个家族。
2. 确認九套并非同一通用身体换色；DeepSeek 鳍尾、Kimi 星月、GLM 耳尾书、Qwen 中式折扇、Gemini 四角彩星、Claude 橙发花饰、GPT 角翼尾、Grok 金色双马尾、OpenCode 机械头饰均可辨识。
3. 检查透明 alpha、无伪棋盘、无裁脚、锚点稳定、帧坐标不越界、动作循环无跳变、相邻工位不被尾翼遮挡。
4. 检查缩放使用最近邻，减少动画尊重系统设置；静态模式不丢状态信息。
5. 使用真实运行与消息检验状态切换、断联恢复、同模型多角色、同伙伴多运行和消息幂等。
6. 原始参考图不默认进入公开分发包；公开素材记录原创制作过程和来源署名，未知许可不宣称已获授权。
