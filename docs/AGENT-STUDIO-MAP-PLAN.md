# 事件工作室与可插拔素材设计

日期：2026-09-09。衔接已验收的跨执行器接力与自动恢复，不改写其证据。整体内测目标仍在进行。

## 交付与顺序

1. 新增只读工作室现场投影：每位伙伴的全部活动运行优先于最近历史，附最后公开事件、来源时间和任务入口。只依据执行器结构化工具类型、明确状态及独立检查身份分区。保留未知，不分析私有推理，不用提示词关键词猜岗位。
2. 新增默认工作室页：明亮的像素房间、角色、区域计数和可操作侧栏；可筛选项目、搜索伙伴、切换名单、选择运行、查看成果、安排工作和发送已有协议的持久消息。全空、断联、同角色多运行、很多角色、长名称均有可用显示。
3. 素材与业务分离：动画仅展示事件。消息立即入库，动画无权投递、调度、取消或重放。减少动态与断联时保持静态事实；同一消息轮询不重复演出。
4. 自定义 PNG 和可选 JSON 动作图集导入：本机持久保存，内容寻址与原子写入，历史外观不被同名更新覆盖。默认单张图片不需要编写 JSON；完整图集支持帧大小、锚点与动作序列。浏览器预览，服务校验 PNG、帧边界、体积与透明图像。错误保留旧配置。图集有缺失动作时如实使用 idle。
5. 复用九套已验静帧，银子工作流补原创房间与真实动作素材，保留出处/哈希/回执。素材未完成时不称完整角色动画已交付。动画制作与接入独立于任务调度。
6. 验收：定向状态投影/素材异常测试，真实浏览器桌面与手机逐按钮，历史真实成果入口；隔离服务注入明确标注的事件夹具验证迁移、断联和消息，不将夹具称为新模型证据。最后更新11章档案中的受影响章节并回读。

## 对抗性审查

| 风险 | 处理与验收 |
| --- | --- |
| 最新80条历史遮住旧活动任务 | 现场查询独立包含所有活动运行；每个伙伴先活动再历史，完整计数与分页名单 |
| 读取工具已结束却永远展示阅读 | 工具完成后回通用工位；只显示最后事件对应的已观察事实，未知不猜测 |
| Codex shell可能测试也可能写代码 | shell归通用执行区；明确file_change才工程，独立review身份才验收 |
| 断联仍活跃动画造成误导 | 标记上次刷新时间并冻结动作，保存最后成功数据，不显示假空或假完成 |
| 模型同名/换模型影响角色 | agent_id作为身份、appearance_id独立，运行快照保留旧外观 |
| 消息动画等于重复发送或假已读 | 稳定request_id，持久回执；已有记录直接显示，重复轮询不再投递 |
| PNG带脚本/路径/超大像素/恶意manifest | 只接受本地PNG字节，不接任意URL或文件路径；验证结构、CRC、解压大小和帧边界；保存时清除无关PNG元数据 |
| 重命名覆盖旧图导致历史改变 | 内容寻址不可变ID；删除只从选择目录隐藏，已用历史图片保留可读 |
| 移动端人物/文字挤在一起 | 地图固定世界尺寸且可横向滚动，手机默认名单；房间仅容纳固定槽位并显式显示其余数量，名单无截断 |
| 地图只是装饰，增加操作 | 点击人物即可看到当前运行、成果、消息和任务入口；保持列表同能力，无自动收费操作 |

审查结论：按上述模块实施。此次不要求额外用户确认；用户已授权本地实现、真实浏览器与所需媒体生成。没有可归因效率提升证据时继续保持未知。
