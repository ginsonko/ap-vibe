# 首次读取与监控摘要修复

当前真实验收捕获：首次overview读取约5秒，首页在此期间把未读取显示为0；完整state数据序列化为约4.6MB（带缩进的本地诊断副本约7.2MB），monitor的last_result/last_error重复明细约1.0MB。项目目录约0.03秒返回，8个已登记项目及第47版档案仍在。不是项目删除。

本轮只修这两个可定位断点：常规状态和Codex状态接口返回监控摘要，保留状态、计数、最后成功时间、原错误码、异常来源数量与少量具体样例。完整明细仍通过codex/status?details=true按需读取，内部poll结果与原始来源不变。摘要必须在复制完整状态之前生成，减少JSON遍历和锁持有时间。首页在overview尚未返回时明确显示读取中，保留已有缓存时继续显示上次数据。

对抗审查：不能把partial改为success；丢失文件错误仍可见，成功时间不能伪造；返回副本不能改变内部状态；未知错误保留原码和下一步，额外字段兼容；没有记录的计数不能凭空填充。完整认知帧和历史仍保持现有接口，本轮不删除或改写认知。异常来源数量与可见样例数量分别记录，不以截断样例掩盖总体。校验大批来源、partial/恢复成功、异常和详细回读；真实页面验证首次读取与项目切换。修改前后读取同一份实际状态量化大小，待运行任务结束再重载服务，绝不强停正在执行的伙伴。
