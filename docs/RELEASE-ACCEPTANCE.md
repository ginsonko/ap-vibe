2026-09-10。本文记录发行包层面的检查；功能长期效果与分项证据见 [内测清单](BETA-READINESS.md)。

## 包内内容与隐私

初始候选提交 `727f0e2`：437 个文件，约 30.6 MB，包含完整源码、预构建前端、Skill/MCP 安装器、文档、59 份第三方原许可、宣传长图和中文教程。GitHub 远端全部文件路径与 Git 内容哈希逐项匹配。

扫描和清单检查没有包含运行数据库、完整会话、私人验收目录、机器安装配置、原始用户参考图或未知根文件。凭据模式命中仅为明确的测试合成值。说明书主入口的本地链接可解析，第三方许可在提交后的内容哈希仍与原件一致。

## 真实安装和页面

从与 GitHub 远端一致的提交生成完整 ZIP，在独立中文目录、独立配置/数据/客户端目录执行真实安装。故意从无关工作目录调用，不传项目根目录，验证安装器选择自己的仓库目录。

安装成功，默认端口被日用工作台占用时自动选择其他端口。健康接口、本次安装的两个 Skill、Codex MCP 实际查询均成功；日用工作台的项目目录保持不变。安装后的七个页面均通过浏览器逐一打开，390 像素手机宽度无横向溢出。

自动登录启动已在此前分项中检查；本次隔离安装明确不登记真实用户 Startup。没有用进程重启替代 Windows 整机重启证明。

## 真实读图新手引导

把最终宣传图和“小白用户已经安装，不知道下一步”的请求交给独立 Codex 任务。它读取已安装 Skill，通过实际 Python 客户端查询资料，检查页面与接入，执行打开实际地址的命令，并返回简单三步引导。任务记录了反馈，没有为一次性安装问答新建长期档案。

首次测试环境只复制登录文件，遗漏了原 Codex 模型连接，触发模型不受支持与网络错误。补齐隔离配置后成功。该失败是测试环境准备问题，记录保留；不应由安装器重写用户原有模型设置。

从完全没有 AP-Vibe Skill 的独立新用户状态开始，仅提供图和完整包的自动安装验收，在最终发布前单独收取和核对。上面这条已经安装的引导不冒充从零安装。

## 宣传素材与教程

1440 × 5920 中文长图，主视觉由 image2 生成后本地排版。九段中文合成语音、字幕、原创轻背景音和产品素材剪辑为 1920 × 1080、24 fps、206.001 秒的 H.264/AAC 视频。

完整视频解码无错误，音轨峰值约 -0.8 dB，九段实际解码帧均检查，安装口令与像素动作画面检查到原尺寸；Edge 中实际开始播放并读回 1920 × 1080。测试 Chromium 不含 H.264 解码能力，因此其播放失败保留为浏览器能力限制，不修改正确的媒体文件。

教程清楚标记品牌插画、流程示意和真实独立演练项目界面。流程示意不当作真实绩效数据。旁白与字幕来自同一分镜，音轨存在和技术可播放不等于所有听众都满意其声音风格。
