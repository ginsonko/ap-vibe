# Claude 会话接入与档案维护推进计划

2026-09-08，承接项目档案revision17与P0实测，不重复模型兼容实验。

## 设计与顺序

1. 普通Claude来源适配器：从当前用户Claude projects目录及配置的附加目录发现顶层session JSONL；文件来源ID与会话ID分开，保留cwd/真实标题或明确首句摘要。只展示user/assistant可见文字、工具名、工具结果状态；不采集thinking、附件原文、工具输入。最近活动不是运行中。
2. 独立只读API和工作室“Claude会话”入口：最近活动优先，列表按文件更新缓存；消息有界读取，增量游标、历史向前翻页、截断/替换重置、失联保留现场。普通会话没有进程所有权，页面不提供停止/发送等假控制。
3. Claude项目上下文生命周期：复用已有MCP context/read/update/feedback与11章/十维合同。下一小阶段补安装Skill、托管允许工具、归因和结束检查；任务未分类按证据归类，不能标题猜测或覆盖旧档案。一次性任务不建立项目。
4. 上述链路真实成立后再做跨工具消息、完成唤醒、认领交接与地图。

## 对抗性审查

- 路径与身份：客户端只提交服务端发现的source_id，不能请求任意文件；解析文件中cwd作来源事实，不凭目录编码猜项目。不改源日志、凭据或其他项目。
- 读取完整性：初次头部+近期窗口，长文件向上翻页；半行等待完整换行才推进增量cursor；轮转/截断返回reset，避免拼接不同代内容；超长行丢弃其内容但报告可见读取边界。
- 性能：目录和每个已更新文件分别缓存；一次只读有界字节，窗口与来源数量可由模块配置调整，不全量反复读取长会话。
- 可见性：缺目录显示尚未发现及操作指引；坏行不白屏；历史滚动时新消息不强制跳底；刷新失败保留数据。只从明确公开块取文字，不输出完整JSON。
- 维护：普通来源与托管执行适配器分开，关掉观察模块不影响任务运行。已有Codex和项目工作流继续使用原入口。

## 验收

本地文件反例覆盖标题、公开文字/工具/隐藏推理、敏感字段脱敏、半行、长历史分页、替换截断、未知来源、目录缺失。真实本机Claude日志核对发现/标题/增量；通过实际CLI在隔离配置目录产生一个普通日志，再由该读取链看到公开输出（不冒充交互终端控制）。浏览器真实点击列表、阅读、历史与切换。档案维护另有真实MCP读写/版本回读才报告通过。

## F10 托管档案纵切（施工前补充）

- 使用本机 Claude CLI `--help` 已确认的 `--plugin-dir` 显式加载本任务插件，避免依赖被 `--setting-sources ''` 关闭的用户配置。Skill 主文放源码，11章协议在运行时从现有规范复制，保持单一规范来源。首先要求执行器加载 Skill，实际日志必须出现成功调用；文件存在不算验收。
- 放行已有 context/read/update/feedback 工具，保持真实 session_id、已选择项目根路径、先读后改、版本冲突重读、历史保留。任务内容本身不适用长期项目时不造档案。没有变化不制造版本。
- 每个托管任务的 MCP 显式连接启动它的工作台地址，不能在隔离服务测试时意外使用本机正式配置。实例配置只包含本地地址和客户端信息，无模型密钥；失联时不启动另一个数据目录的服务。
- 测试使用独立服务、独立测试项目和真实 CLI；先用本地模拟验证发现/协议，再用已授权模型验证真实遵循和增量更新。旧项目、历史事故和人工字段必须保留。模拟输出与真实模型结果分别标记。
- 暂不全局写普通 Claude 设置：官方网页当前403/浏览器超时，先完成已由CLI确认的显式插件路径，随后验证 SessionStart 的真实载荷和普通安装流程。不是要求用户做额外确认。

自审：不新增认知系统、不把11章键齐全当内容真实、不把本机身份隔离当OS沙箱、不把模型自述当写入回读。并发更新复用已有CAS；模型请求不确定不自动重放。运行失败仍保留输出和可恢复的待写补丁。

## 普通 Claude 安装纵切

原生用户 skills 目录安装同一主文和共享参考，安装脚本保留已有设置；MCP通过本机CLI已确认的 `mcp add-json --scope user` 注册。SessionStart/UserPromptSubmit 从真实hook输入提取session_id/cwd，输出小目录和真实地址，不灌入全部历史；Stop最多补记一次且遇服务故障正常退出，不形成无限拦截。先在独立Claude目录用真实CLI与本地模拟响应验证hook输入、Skill发现与现有设置保留，再安装本机默认目录。不把模拟协议验收声称为普通交互任务模型质量保证。缺少项目归类接口仍明确列入下一步，不让普通问答随意创建项目。
