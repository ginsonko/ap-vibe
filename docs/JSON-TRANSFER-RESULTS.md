# JSON 传输现场回读

2026-09-10 在所有托管伙伴空闲时正常重启服务，加载 gzip 协商。以 identity 和 gzip 分别请求同一时间窗口的实际页面数据：

| 现场接口 | 原始字节 | 传输字节 | 解压后结果 |
| --- | ---: | ---: | --- |
| state | 3,586,115 | 642,394 | SHA256 与原始结果相同 |
| data | 568,908 | 116,995 | SHA256 与原始结果相同 |

两次均返回 200，Content-Length 为实际传输长度。独立真实 HTTP 检查还验证了中文字节保持、客户端拒绝 gzip、identity 优先及 503 错误内容和状态保持。

数据仍是完整 JSON；传输缩小不代表查询或渲染同比提速。现场第二次请求可能命中既有短缓存，不能把两次耗时差全算成压缩收益。全前端主包仍约 762KB，存在打包体积提示。
