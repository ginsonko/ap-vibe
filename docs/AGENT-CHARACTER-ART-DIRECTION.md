用户希望认识这些设定的人能一眼认出来源风格，允许重新设计而非完全一致。保留家族轮廓、发色、主要装束和标志性配饰；同一模型多个Agent通过姓名牌、色带和小配件区分，模型家族与执行器身份分别显示。外观不限制模型选择，未知模型可自定义。

素材合同：建议先统一64×64基础单帧，按实际地图显示比例检验；可调整但同套脚底锚点一致。提供正背左右方向，idle/walk/work/read/talk/wait/rest状态及帧率/图集配置。移动动画不拖延消息投递。工具状态不足时显示处理中，不通过关键词编造行为。

先生成一张全员Q版像素设定预览校准比例与辨识度，再生成单角色图集并检查透明边缘、调色板、脚底锚点、帧间身份一致性与循环动作。地图内用实际尺寸查看，提供减少动画和普通列表。保存生成请求与实际费用/未知字段、素材出处和分发许可说明。不得将图中关于模型性格、能力或价格的梗文当作真实能力评估。
