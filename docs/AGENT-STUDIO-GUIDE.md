# Agent 工作室使用说明

把任务交给适合的伙伴，让进度、成果和交接留在同一个工作台。你仍然可以在 Codex 或 Claude Code 中照常工作，不需要手动搬运整段聊天。

本文对应 v0.2.0-beta.1 Windows 个人内测版。公开下载版本以 Releases 标注为准；功能与发行实测范围见 [本版验收](BETA-2-ACCEPTANCE.md)。

## 第一次使用

1. 打开工作台的 **Agent 工作室 → 伙伴与配置 → 添加角色模板**，保留推荐项并添加。模板已填写地址、模型、职责和外观；首次使用时，芙芙会自动接入尚未配置的管理办公室。已有伙伴和管理员选择会保留。
2. 展开 **快速配置多个伙伴**。使用银子 API 智能 Key 时，可以给所选伙伴一次填入 Key；使用其它服务时，可先统一 URL，再逐个编辑 Key 和模型。Codex 使用本机登录，不参与这一步。缺少 URL、模型或 Key 的 API 伙伴会留在宿舍等待配置。
3. 开启 **自动 Agent 协作**，再到 Codex 或 Claude Code 中照常提出需求。复杂任务会按配置与实际能力分工，小任务可以直接完成；打开工作室查看计划、输出和成果。

推荐模板包含专职管理伙伴、执行伙伴、独立核验伙伴、经济 Claude 和本机 Codex。芙芙默认使用本项目已有管理流程实测的 `grok-4.6`；形象仍是芙芙。也保留可选 Gemini 管理模板，在管理办公室可以改用你的连接。模板的履历说明会区分实测与候选，不把模型名称当作质量保证。

银子 API 的建议配置是：创建智能 Key、分组倍率上限设为 2、全选分组，并设置便于管理的额度；这些是建议，不限制其它服务。需要分别控制消耗时，可给每位伙伴使用独立 Key。保存配置不会调用模型。后续可先安排一件有明确成果的小任务，核对当前渠道的工具与交付表现。

模板暂时加载失败时可直接重试。配置保存结果未确认时保留输入，再次保存会核对原请求；若已保存、只是列表刷新失败，页面会分别说明，点击刷新列表即可。

例如，把一个伙伴叫作“前端设计师”，职责写“改善中文页面的排版、配色、可访问性与移动端体验”。URL 是否包含 `/v1` 以你的提供商说明为准；请求模型名必须是你的渠道实际支持的名称。

同一个模型可以配置多位伙伴。名字和像素外观不会改变模型能力，人设也不会覆盖用户目标、实际证据或工具权限。

## 让当前任务自动分工

打开工作室的 **自动 Agent 协作**，或者在 **项目与记忆** 中只为当前项目开启协作。项目和会话可以覆盖全局默认值；界面显示当前实际采用的设置。

之后你可以像平常一样说：

> 请改善这个应用的手机端页面，保持已有按钮和业务功能，完成后检查关键交互。

Skill 会让原会话读取项目档案和可用伙伴，把适合独立完成的工作交出去，并保存成果返回入口。没有合适的伙伴时，原会话继续做；任务很小时也可以直接完成。不会为了显得“多人协作”而强行拆分。

你也可以明确指定一次分工：

> 请让已配置的 Claude 前端伙伴美化这几个页面。先把设计目标、不能删的功能和相关文件讲清楚，完成后由你验收。

明确委托不需要先修改全局协作开关，也不会把所有其他项目都改成自动协作。

## 地图和任务状态怎么读

| 看到什么 | 代表什么 | 接下来可以做什么 |
| --- | --- | --- |
| 普通 Codex / Claude 角色 | 发现了对应公开会话，标题与进度来自实际记录 | 点击角色，看近期消息或具体任务 |
| 角色标注“专注中” | 这个普通会话没有开启自动协作 | 仍可查看；不会被自动建议或接续打扰 |
| 查阅区、工程区、测试室 | 由当前公开工具活动或任务阶段推导的位置 | 打开详情核对实际输出 |
| 管理办公室 | 管理伙伴在安排计划/处理异常，或本地调度器在值守 | 查看分工、依赖、事故、决定和未完成项 |
| 宿舍 | 空闲、已结束或预算暂停等状态 | 具体原因看角色标签；休息动作本身不调用模型 |
| 成果待验收 | 作者交付了文件，尚未完成独立检查 | 打开成果，核对标准后保存通过或需要修改 |
| 连接恢复中 | 页面暂时无法读到新状态，保留上次现场 | 后台任务状态以重新连接后的回读为准 |

超过一层工位时可以切换楼层，也可以用名单找到全部角色。动画只是公开事件的表现，不能当作模型正在思考、已读消息或已经完成工作的证据。

## 管理员和故障接续

管理员默认叫芙芙，名字、人设、外观和模型均可修改。她参与计划分工、依赖和异常协调，读取必要资料并选择可用伙伴；没有事件时由本地程序等待，不持续调用模型聊天。计划登记成功与管理员实际回复分别显示，未回复时不会假称已接管。

自动接续需要当前任务处于协作范围内，并有明确的失败证据。正常等待、运行缓慢和用户取消分别处理。任务用持久账本认领，多个伙伴不能同时拥有同一份执行权限。

对于 AP-Vibe 托管的任务，系统能核对自己启动的执行器是否退出，再按原任务及已配置候选接续。对于普通外部终端，如果只能确认错误、无法确认旧进程退出，伙伴会在新的成果目录中诊断和准备补丁，避免两边同时改原文件。收费或部署结果未知时先核对原请求，不能把重复请求当作“恢复”。

成果会回到原会话的收件箱。支持的 Codex 返回通道可以排队唤醒；普通 Claude 终端通过下次 Hook / Skill 读取收件箱。当前版本不承诺即时唤醒任意外部终端。

管理员连接失败时，本地账本仍可按照原先授权的候选继续安排；所有候选都不可用时保存任务和原因，等待恢复。没有通过的新成果不会被当成最终完成。

## 最后一句话断了，文件还能用吗

工作室启动的 CC 遇到超时、临时过载或响应截断，会在原任务内恢复当前模型请求。默认最多重试5次，加上首次共6次尝试；成功后继续原来的上下文和工具进度。可以在 **伙伴与配置 → 编辑 → 偶发请求失败后，最多重试几次** 修改，0为关闭。此设置适用于之后启动的运行，不改变正在进行的运行，也不会重新提交过去失败的任务。

恢复时能看到当前重试序号。一轮响应完整后才显示并交给CC执行，避免半截工具指令重复执行；因此启用恢复时，文本按整轮显示。重试可能增加API费用，每次尝试分别记录用量，查不到的费用仍标为未知。认证或参数错误直接报告，临时错误用尽次数后才退出，管理员再按原任务的接手设置安排。用户停止、客户端退出或已配置额度耗尽时不再继续重试。

可以先查看 **任务与输出 → 成果文件**。有些运行已经写完文件，却在最后回复时遇到渠道超时。

运行确认停止后，可以读取实际文件，点击 **用于本次验收**，再提交验收结论。系统保存文件指纹，并保留原来的错误和用量。缺陷应选择“需要修改”；没有证据时保留待检查。验收不会重新发起那次结果不明的模型请求，也不会复活已取消的任务。

## 用“饱食度”控制自己愿意投入的额度

预算默认不限额。你可以按伙伴设置 Token 或金额上限，也可以保持不设置；达到已配置的限额后暂停新增工作，投喂增加额度后再继续符合条件的任务。

- Token 由能够取得的用量记录累计；缓存字段单独保留，避免重复累计。
- 金额需要可用价格。未配置价格时显示 **0，未估算**，含义是没有金额估算，不是免费。
- CLI 给出的估价与提供商账单可能不同；两者应按来源区分。
- 本地上限不是提供商的硬扣费上限，已经发出的请求仍可能产生用量。

建议在提供商侧给不同伙伴使用不同 Key，并按需要设置 Key 额度上限。你也可以让 Codex 帮忙填写本地参考价格：

> 请读取我这个渠道的价格页，核对模型名、币种、每百万 Token 单位，以及输入、输出、缓存价格；给对应伙伴填写参考价格，记录来源和日期。查不到的价格保持未知，不要猜。

不要把 Key 粘贴到公开任务、截图、README 或宣传图。需要换 Key 时在伙伴配置里更新即可，历史任务保留原配置版本的归属。

## 通用示例：把图片检查交给合适的视觉模型

在原任务中提出图片检查需求即可，不需要寻找专用业务页面。大量图片使用批次工具，不为每张图启动一个完整编程 Agent。先用代表性样本确认模型能读取你渠道的多模态输入，再扩展到整个目录。个人非商业内测用非经营素材；商业生产需另行授权。

完整步骤、提示词和未知结果处理见 [批量图片验收](BATCH-IMAGE-QA.md)。已有小样说明主链路可以工作，不能直接推断任意商品、4000 张图片的质量、账单或节省比例。

## 离开之后发生了什么

点击 **故事回放**，选择最近一小时、一天或七天。可以只看工作交流、跳到某一幕、暂停查看原文，并选择 **1 / 2 / 4 / 8 倍**。长时间等待被折叠，原速时按演出节奏呈现走路和对话；倍速让这一轮回看更快。

回放只读取已保存的事件，不会重新派发任务、发送消息或消耗模型。保存图片前可以勾选 **分享时隐藏姓名和消息**；文件只在本机生成，不自动上传。

QQ 接口本版默认关闭，不需要 QQ 机器人才能使用管理伙伴。

## 更新与资料保留

新任务会触发可合并的版本检查。网络离线时原任务照常继续；有可用新版本时先下载检查，在符合空闲条件时切换。配置、Key、项目档案、任务账本和角色素材保存在原数据目录，代码升级不应创建一个空工作台来替代原资料。

桌面启动器会发现当前安装的实际服务地址；服务已运行时打开它，未运行时先启动。端口发生退避时也应使用返回的实际地址。

如果出现无法自动处理的升级错误，工作台应保留原资料与可继续入口，并明确说明当前运行版本。不要自行删除数据目录或重复安装到新数据目录来“解决”空页面。
