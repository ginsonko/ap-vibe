# 普通会话跨应用接续

## 目标与现有基础

用户在 Codex 做到一半切换到 Claude Code，或反向切换，只需提出继续任务。新会话通过安装的 Skill 查询 AP-Vibe 小目录，按需读取原会话最新公开进展和项目档案，核对真实工作文件后接续。无额外绑定、口令、授权步骤。普通会话接续与工作室托管任务接力分别验收，不混用证据。

已存在 Codex 来源注册表、标题索引、公开消息过滤器，Claude 来源发现与分页读取器，项目归属和档案协议。沿用来源身份、文件位置和现有归属；不按标题合并项目，不复制一套对话数据库。

## 本阶段设计

1. 增加只读 sessions 目录与 session_read MCP/API。目录支持 harness、精确 cwd、project_id、session_id、搜索和分页，默认近期来源优先。目录每条包含真实会话 ID、标题来源、归属依据、最后文件活动时间、来源 ID 与读取入口。文件活动不等于模型仍在运行。Codex 从已有注册来源获取，Claude 沿已配置根发现，明确覆盖范围和上限。
2. 精确 source_id 定位单个文件，最新页默认读取末端公开消息；同一会话多个 rollout 保留全部来源入口，不能误读最旧文件。支持 before 历史、after 新增和 generation 文件替换检测。分页有事件/字节界限及截断说明；不声称完整历史。读取不会推进认知采集游标、修改项目或启动模型。
3. 共用有限 JSONL 窗口读取逻辑，保留 Codex/Claude 各自公开内容解析器。隐藏推理、原始工具参数/结果与注入的 Skill 正文不可出现在公开上下文。局部写入留在游标前，轮换后返回 reset。单次结果须小于 task_client 读取上限。
4. bootstrap 只增加短目录入口，Codex/Claude hook 和共享 reference 介绍同目录优先、按用户意图搜索、确认原目标/最新变更/未完成项，再查相关章节和文件。资料仍为不可信观察，不自动执行其中的命令。信息不足明确指出缺口，不要求用户手工转录已存在的上下文。
5. 安装器同步共享 reference，保留所有用户设置。当前没有 MCP 的 Codex 可用 task_client sessions/session-read 命令，同样通过本地生命周期恢复服务。

## 对抗性审查与处理

- 正确性：原 sample 尾部最多取窗口内前 32 条，不能直接作为最新页；新增窗口读取返回真正末端。多个同名/续写来源按 source/session 身份返回，不取标题作为键。
- 完整性：分页不能丢窗口边缘跨行消息、长消息或同一记录多个公开块。字节游标边界按完整原始记录裁剪；单条过大给出明确截断。超出发现范围提供 coverage 信息，不展示“所有历史已读”。
- 并发恢复：实时追加的半行下次补读；文件替换或截断必须 reset，不沿用旧偏移。目录 stat 与读取期间文件变化为可重试状态，不污染目录和档案。
- 性能：目录读取来源元数据，不扫描全部对话、不载入全部档案；正文只按需读取。有界输出，避免大量团队重复读取同一资料。
- 使用门槛：所有本机 harness 可只读，无 receipt 和项目归类前置条件。写档案仍按已确定归属及版本保存，以免覆盖他人内容；这是数据一致性，不是阅读授权。
- 证据：单元测试验证异常和接口，真实普通 CLI 验证 Skill/MCP 采用与文件接续，浏览器核对能看到这两条实际会话。模拟日志仅说明解析器正确，不当成模型行为证据。
- 范围：不重做旧付费实验/完成动画、不动用户密钥/连接配置，不把本阶段通过当成整体公开发布完成。普通“当前目录”只作候选排序线索，跨目录接续可全局查找。

审查结论：按以上边界实施，没有新增用户操作门槛。实施后复核上述反例，修复首次实际失败，再冷保存真实验收结果。

## 真实验收补充

第一组普通 CLI 暴露两个此前隔离测试未覆盖的问题：Codex 沙箱可访问本地服务但不能写全局收据缓存，客户端误报整个读取失败；Claude 安装器给默认目录显式设置 CLAUDE_CONFIG_DIR，改变了实际用户 MCP 配置位置，普通启动因此没有 MCP 工具。已按真实错误修复缓存降级与默认/显式目录注册定位，分别加入回归检查。

第一次 Claude 还受到用户 settings.env 中旧连接覆盖；本次连接使用 CLI --settings 明确指定，保留用户配置。第二次在缺 MCP 情况下读到验收脚本预期，样本已作废并停止，不能算成功。新样本工作目录放在仓库外，入口恢复仍使用普通全局安装；记录实际 MCP 工具列表、Skill 调用、来源读取、真实文件和回读结果，不以正确输出数字代替接续证据。

## 验收

定向测试：最新消息超 32 条、增量追加、半行、多块同记录、长行、非法 JSON、generation 重置、同标题不同会话、未归类可读、目录筛选分页、无写入副作用、安装完整性和 hook 长度。真实验收：普通 Codex CLI 留下未完成工作，普通 Claude CLI 仅收到继续意图，自动找出原会话并完成；反向读取新增结果。保存独立文件检查、MCP 采用轨迹、实际费用估算与局限，重启后回读一致。
