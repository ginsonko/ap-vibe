# v0.2.0-beta.1 Windows 个人内测版

本版集中交付已有四项基础能力、通用工作室协作、首用引导和无损版本维护。正式 Release 的附件与指纹以同标签清单为准。

## 功能范围

任务监看与 Codex/Claude 统一会话、11章长期档案和十维证据说明、按需上下文、逻辑观察、默认关闭的 AP 认知实验；工作室提供伙伴连接、计划分工、依赖、真实成果与独立检查、四层地图、芙芙配置和1/2/4/8倍回放。

此前正式本地页面验收覆盖九个注册项目切换、工作室入口、真实Claude会话、手机显示；一个实际计划完成管理分工、依赖、检查与整批返回。作者样本主要使用Claude Code执行grok-4.6，不能当跨模型普遍质量对照。

首用UI曾由 Claude CC Max 部分交付，因派发者自设12回合而提前退出。有效帮助修改已采纳，缺失的配置顺序与说明由主任务完成并检查；失败历史保留，不把这次原Claude交付记成全通过。已修正派发约定。

缺少 Claude Code CLI 时，安装说明和 Skill 会提示并请求用户允许自动安装；依赖该执行器的伙伴暂不可用，基础能力和已有Codex执行器继续可用。安装后按原配置补接入，不要求重新填写所有Key。仅安装不调用付费伙伴。

## 仍需内测反馈

另一台实体电脑、各用户Windows策略、真实整机重启和多日运行继续由首批内测观察。普通Claude终端通过下次Hook/Skill读取返回，不能即时唤醒任意终端。AP真实多模态输入与长期收益尚未证明；多伙伴不保证每项任务更快或更省。

个人非商业使用；经营生产需另行授权。外部模型/宿主可能收费，金额未估算不等于免费。新宣传图与视频未随本版制作发布。

首次从[文本安装口令](BETA-INSTALL-PROMPT.txt)开始，安装后按[体验任务卡](TRY-IT.md)选择一两个真实场景即可。反馈目标、操作、版本与脱敏截图，不上传Key、完整会话或数据库。历史阶段的验收范围见[BETA-READINESS](BETA-READINESS.md)。
