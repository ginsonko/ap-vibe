# 一次由 Agent 自主建立的协作链

实测日期：2026-09-09 UTC（本地跨至 09-10）。这是合成销售记录的小样本，真实连接、真实 Claude CLI、真实 MCP、真实成果；不是模拟模型输出。

## 已经发生的事情

规划 Agent 加载共享 Skill、读取当前项目及伙伴/任务目录，根据真实输入自行创建三项业务任务：金额核对、异常核对、成果汇总。它把一项工作交给空闲伙伴，另一项排给自己，正常结束规划回合后由调度器启动。规划者还保存并回读了包含实际任务ID的 plan.json，并广播一次共同核对规则。

两个工人的实际运行区间有约 6.1 秒重叠。每项成果返回后，服务自行建立独立检查任务；两项检查通过后才放行汇总。汇总 Agent 读取真实工人文件，保存 summary.json 与中文 report.md，再交给独立伙伴检查。三项业务任务均 completed/accepted。没有由主任务手填这些成果或冒充模型工具提交。

主任务另外按输入规则核对：总额 23500 cents，异常仅 row3（重复）、row5（缺金额）、row8（负金额）；退款与取消是排除项，不应混成异常。汇总引用的四份工人成果路径、运行ID和 SHA256 均与实际文件一致。原输入未改动。规划文件与最终结果已经独立回读。

## 工程与界面

- MCP 已提供伙伴目录、分页任务目录、创建/更新、认领、停止后释放、归档、广播与成果读取；沿用原任务池、CAS和幂等回执。
- Codex/Claude 共用协作参考，Claude允许工具与MCP目录同源；全局安装副本和托管插件都含参考文件。
- HTTP验收覆盖精确读取/分页/项目筛选、候选不存在、抢占冲突、托管发送者归因、广播去重与冲突、归档响应丢失后同请求恢复。
- 保留已停止且待验收父任务的原有归档行为，迟到裁决不能偷偷应用；运行中任务仍不能归档。
- 真实浏览器打开任务依赖、独立报告及最终成果；1440和390宽度无JS错误。手机长任务说明原先有内部裁切，已改为Markdown、自动换行和有限高度滚动，验证元素自身边界而非只看整页宽度。

## 成本与结论边界

这轮共 7 次托管运行：规划、两个工人、三个独立检查、汇总。CLI累计报告输入 1,873,793 tokens、输出 38,785 tokens，费用估算约 10.34 USD。它是CLI的用量/估算，供应商实际结算未核对，不能作为真实收费报价。

这份八行数据的小任务，为验证机制刻意安排了完整分工和多次检查，协作开销明显。没有单Agent对照，也没有足够样本支持节省费用或提高质量的结论。实际产品应按工作复杂度和独立性选择单Agent或团队；不能把每个小需求都拆成团队。源只定义cents，报告中人民币换算带条件说明，不代表输入定义了币种。

仍待完成：普通跨应用会话无手工接续、根据真实可比任务更新能力评估、主动搭话与接手的更广样本、其余八套角色动作和真实素材委托、全部页面与安装发布验收。
