# 手动档案编辑的字段关联

真实浏览器项目管理验收在尚未保存任何修改前发现：Field将删除按钮和文本域一起嵌套在label内，隐式关联会指向先出现的按钮，按字段名称无法访问文本域。这影响键盘/辅助工具，也使标签点击不能可靠定位输入框。

修复采用React useId生成稳定字段ID，显式label关联对应textarea/input/select；删除按钮放在标签外，保留原递归结构和数据类型、取消/新版本保存流程。常见id与user_note增加中文名称，未知自定义字段继续原名显示，不调用模型猜测。

审查：数组每项独立ID、重排后标签与控件同时渲染，字段删除仍只改草稿；不改变保存API、旧版保留、并发版本检测或人工编辑优先规则。不在真实项目上伪造资料。

验收在原隔离实例通过真实表单按名字输入，回读保存结果；独立执行导出、新建/改名、归档/恢复，并检查项目ID、原决定与旧版本。第一次失败无写入，保留收据后才重试；任何已保存动作不因浏览器超时自动再提交。
